# Data Folder

This folder contains data files used for the U.S. wind energy potential and tornado risk analysis.

## Files

| File | Description |
|---|---|
| `raw/wind-power-production-us.csv` | Historical wind power production data for the United States and individual states. |
| `raw/tornados.csv` | Tornado event records used to summarize tornado frequency and magnitude by state. |
| `raw/total_wind_capacity_80m.csv` | State-level estimated wind capacity potential at 80 meters. |

## Data Sources

- Kaggle: Wind Power Production US 2001–2023
- Kaggle: Tornados Dataset
- LandGate: Average Wind Speeds by State
- U.S. Department of Energy WindExchange: Total Potential Wind Capacity

## Notes for GitHub

The uploaded CSV files are small enough to keep in this repository. Do not upload private API keys, especially `kaggle.json`.

If you later download larger raw datasets, keep them local or add them to a larger-data storage location, then document the download instructions here.
