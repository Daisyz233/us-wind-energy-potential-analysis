# GitHub Upload Guide

## Recommended repository name

```text
us-wind-energy-potential-analysis
```

## Repository description

```text
Solo data science project analyzing U.S. wind energy production, wind capacity potential, average wind speed, and tornado risk using Python visualization and K-Means clustering.
```

## Recommended GitHub settings

- Visibility: Public
- Add README: No, because this folder already includes one
- Add .gitignore: No, because this folder already includes one
- License: Optional, MIT is fine for a portfolio project

## Upload steps

1. Unzip this folder.
2. Create a new GitHub repository.
3. Open the unzipped folder until you see `README.md`, `data/`, `notebooks/`, `src/`, and `visuals/`.
4. Upload those contents to GitHub.
5. Commit with:

```text
Initial clean portfolio structure for wind energy analysis project
```

## Important notes

The `src/` folder is now included and cleaned for GitHub. The `config.py` file does not contain private credentials.

Do not upload `kaggle.json`.
